# Task App - Angular

A simple task management application built with Angular. This project demonstrates the use of Angular features such as components, services, and reactive state management.

---

## Features

- Add, edit, and delete tasks.
- Mark tasks as complete.
- Filter tasks by user.
- Responsive design using Angular components.
- State management with Angular Signals (if applicable).

---

## Technologies Used

- **Angular**: Frontend framework.
- **TypeScript**: Programming language.
- **HTML/CSS**: For UI design.
---
